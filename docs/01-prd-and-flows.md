## 1. 제품 정의

**한 줄:** 가족이 초대한 사람끼리만 사진을 올리고 중첩 폴더로 정리하며, 원본은 각자 연결한 클라우드(1차 Google Drive)에 저장되는 비공개 공유앨범.

**핵심 명제:** "사진은 우리 가족만 보고, 원본은 우리 것이다."
일반 가족앨범 앱은 사진을 사업자 서버에 맡긴다. 이 앱은 **원본이 사용자 소유 클라우드에만** 존재하고, 서비스가 종료돼도 Drive 폴더에 사진이 그대로 남는다.

**타깃:** 30~50대 부모가 스페이스를 만들고, 조부모·형제를 초대해 아이 사진을 공유하는 3~8인 규모.

### 차별점 3가지 (경쟁 대비 유지해야 할 것)
1. **BYO 스토리지** — 원본이 사용자 Drive/NAS에 저장. 용량 과금이 앱이 아니라 사용자 클라우드 요금제에 붙는다.
2. **중첩 폴더** — `가족 > 2026 > 여름휴가 > 제주`. 대부분의 가족앨범 앱은 평면 앨범만 제공한다.
3. **지정 앨범 자동 업로드** — 폰의 특정 앨범에 넣기만 하면 가족 앨범에 올라간다(iOS는 best-effort).

### 명시적 비목표 (Phase 4까지 만들지 않는다)
- 앱 자체 무제한 클라우드 저장소
- 1초 하이라이트 자동 영상, 포토북·인화 커머스
- 아이 성장 기록 전용 페이지, AI 얼굴 인식 자동 분류

## 2. 역할과 권한

| 권한 | Owner | Admin | Member | Viewer |
|---|:---:|:---:|:---:|:---:|
| 사진 조회·다운로드 | ✅ | ✅ | ✅ | ✅ |
| 사진 업로드 | ✅ | ✅ | ✅ | ❌ |
| 자기 사진 삭제 | ✅ | ✅ | ✅ | ❌ |
| 남의 사진 삭제 | ✅ | ✅ | ❌ | ❌ |
| 폴더 생성·이름변경·이동 | ✅ | ✅ | ✅ | ❌ |
| 폴더 삭제 | ✅ | ✅ | ❌ | ❌ |
| 댓글·반응 | ✅ | ✅ | ✅ | ✅ |
| 멤버 초대 | ✅ | ✅ | ❌ | ❌ |
| 역할 변경·강퇴 | ✅ | ✅(Owner/Admin 제외) | ❌ | ❌ |
| **스토리지 연결·해제** | ✅ | ❌ | ❌ | ❌ |
| 스페이스 삭제 | ✅ | ❌ | ❌ | ❌ |

**스토리지 연결을 Owner 전용으로 좁힌 이유:** 연결 계정이 바뀌면 기존 에셋의 원본 위치가 통째로 무효화된다. Admin에게 열어두면 사고 시 복구가 불가능하다.

**Owner는 스페이스당 정확히 1명.** 이양은 가능하되 새 Owner가 자기 스토리지를 연결하지 않으면 기존 연결이 유지된다(에셋 유실 방지).

## 4. 핵심 정책 결정

| 항목 | 결정 | 근거 |
|---|---|---|
| 폴더 깊이 | **무제한** (UI 브레드크럼은 4단부터 `…` 축약) | Drive에 깊이 제한이 없고, 인위적 제한은 사용자 혼란만 만든다 |
| 사진의 폴더 소속 | **단일 폴더 + 이동**. 다중 태그는 Phase 4 | 폴더=Drive 실제 폴더와 1:1 미러링이므로 다중 소속이 물리적으로 불가 |
| 파일명 충돌 | `{assetUuid}_{originalName}` | 같은 이름 파일을 여러 명이 올려도 충돌 없음 |
| 삭제 | Phase 1은 **Drive 휴지통으로 이동**(`trashed=true`), 영구삭제 아님 | 실수 복구 가능. Phase 2에서 앱 내 휴지통 UI 추가 |
| 지원 포맷 | HEIC/JPEG/PNG/WEBP, MP4/MOV | HEIC는 원본 그대로 업로드, 썸네일만 JPEG 변환 |
| 스페이스당 스토리지 | **1개** | 폴더별 오버라이드는 Phase 4 옵션 |
| 미연결 시 | 업로드 버튼 비활성 + "저장소를 연결해 주세요" 유도 | |

## 5. 화면 플로우

### 5.1 전체 네비게이션

```
[스플래시]
   ├─ 미로그인 ─→ [온보딩] → [로그인] ─┐
   └─ 로그인됨 ───────────────────────┤
                                      ↓
                            [스페이스 목록]
                     ┌────────────┼────────────┐
              (없음) │      (선택) │     (초대링크로 진입)
                     ↓            ↓            ↓
              [스페이스 생성]  [스페이스 홈]  [초대 수락]
                     ↓            │
              [저장소 연결]       │
                                  ↓
        ┌──────────┬──────────┬──────────┬──────────┐
     [폴더]    [타임라인]   [업로드]    [알림]     [설정]
        ↓                                            │
   [폴더 브라우저] ─→ [그리드] ─→ [사진 상세]        │
                                                     ↓
                              ┌──────────┬───────────┬──────────┐
                          [멤버·역할] [저장소 연결] [자동업로드] [알림설정]
```

### 5.2 온보딩 → 첫 업로드 (신규 Owner, 가장 중요한 경로)

```
1. [온보딩] 3장 슬라이드
   "가족만 보는 앨범" / "사진은 내 클라우드에" / "폴더로 정리"
                ↓
2. [로그인] Google 로그인 · 이메일 매직링크
                ↓
3. [스페이스 생성] 이름 입력 (예: "박씨네")
                ↓
4. [저장소 연결]  ← 여기가 이탈 최대 지점
   ┌─────────────────────────────────────┐
   │ 사진을 어디에 저장할까요?             │
   │                                     │
   │ ● Google 드라이브        [연결하기] │
   │ ○ 네이버 MYBOX   (연동 준비 중)     │
   │ ○ 개인 NAS       (곧 지원)          │
   │                                     │
   │ 원본 사진은 선택한 저장소에만          │
   │ 보관되며, 저희 서버에는 저장되지       │
   │ 않습니다.                            │
   └─────────────────────────────────────┘
                ↓ Google 동의 화면 (drive.file)
                ↓
5. [연결 완료] "/FamilyShare/박씨네 폴더를 만들었어요"
                ↓
6. [가족 초대]  링크 복사 · QR 표시 · 나중에 하기
                ↓
7. [스페이스 홈] 빈 상태 → "첫 사진을 올려보세요" CTA
                ↓
8. [업로드] 사진 선택 → 폴더 선택 → 업로드 진행률
```

**이탈 방지 장치:** 4번에서 "나중에 연결"을 허용한다. 단 스페이스 홈 상단에 상시 배너 + 업로드 버튼 비활성으로 유도한다. 연결을 강제하면 앱을 구경조차 못 하고 이탈한다.

### 5.3 초대 수락 (게스트, 두 번째로 중요)

```
카톡으로 받은 링크 탭
        ↓
앱 미설치 → 스토어 → 설치 후 딥링크 복원 (Universal Link / App Link)
앱 설치됨 → 앱 실행
        ↓
[초대 수락] ← 미로그인이면 로그인 먼저
   ┌─────────────────────────────────────┐
   │       [박씨네] 앨범에 초대됐어요       │
   │        초대한 사람: 박○○              │
   │        멤버 5명 · 사진 342장           │
   │                                     │
   │  ※ 사진 미리보기는 표시하지 않는다     │
   │                                     │
   │       [참여하기]   [거절]             │
   └─────────────────────────────────────┘
        ↓ 참여
[스페이스 홈] — 이 순간부터 콘텐츠 노출
```

**수락 전 비노출 규칙:** 초대 화면은 스페이스 이름·초대자 이름·멤버 수·사진 개수만 보여준다. 썸네일·폴더명·멤버 목록은 **서버가 응답에 담지 않는다**(클라이언트에서 숨기는 방식 금지).

### 5.4 폴더 브라우저 → 사진 상세

```
[폴더 브라우저]
 ┌───────────────────────────────────────┐
 │ 박씨네 > 2026 > 여름휴가          [+] │  ← 브레드크럼(탭하면 상위 이동)
 ├───────────────────────────────────────┤
 │ 📁 제주      📁 부산                   │  ← 하위 폴더(커버 썸네일)
 │   84장        31장                     │
 ├───────────────────────────────────────┤
 │ [사진 그리드 — 이 폴더 직속 사진]        │
 │  ■ ■ ■                                 │
 │  ■ ■ ■   ← 길게 누르면 다중 선택 모드    │
 └───────────────────────────────────────┘
        ↓ 사진 탭
[사진 상세] 핀치 줌 · 좌우 스와이프
   상단: 올린 사람 · 촬영일
   하단: [다운로드] [폴더 이동] [삭제] [댓글(P2)]
```

**다중 선택 모드 액션바:** `n장 선택됨 | [다운로드] [이동] [삭제] [취소]`

### 5.5 업로드 플로우

```
[+] 탭
  ↓
[사진 선택]  expo-image-picker 다중 선택
  ↓
[대상 폴더 선택]  기본값 = 현재 보고 있던 폴더
  ↓
[업로드 큐]  화면을 벗어나도 계속 진행
 ┌───────────────────────────────────────┐
 │ 업로드 중 3/12                        │
 │ IMG_0421.HEIC  ▓▓▓▓▓▓▓░░░  68%        │
 │ IMG_0422.HEIC  대기 중                 │
 │ IMG_0419.HEIC  ✕ 실패  [재시도]        │
 │                                       │
 │ ☑ Wi-Fi에서만 업로드                   │
 └───────────────────────────────────────┘
  ↓ 완료
스페이스 홈 그리드에 반영 + 다른 멤버에게 실시간·푸시
```

**큐 규칙:** `expo-sqlite`에 영속화한다. 앱을 죽였다 켜도 미완료 항목이 남아 있고, 재개 가능한 항목은 Drive resumable 세션 URI로 이어받는다(세션 1주 유효).

## 6. 빈 상태 / 오류 카피 (한국어 확정)

| 상황 | 카피 |
|---|---|
| 스페이스 없음 | "아직 앨범이 없어요\n가족 앨범을 만들어 초대해 보세요" |
| 저장소 미연결 | "사진을 올리려면 저장소를 연결해 주세요" |
| 폴더 비어 있음 | "이 폴더에는 아직 사진이 없어요" |
| 네트워크 없음 | "인터넷 연결을 확인해 주세요. 올리던 사진은 연결되면 이어서 올라가요" |
| Drive 용량 부족 | "Google 드라이브 저장 공간이 가득 찼어요.\n공간을 정리한 뒤 다시 시도해 주세요" |
| Drive 재인증 필요 | "Google 드라이브 연결이 만료됐어요.\n다시 연결하면 밀린 사진이 이어서 올라가요" |
| 강퇴됨 | "이 앨범에서 나가게 되었어요" |
| 초대 만료 | "만료된 초대 링크예요.\n초대한 분에게 새 링크를 요청해 주세요" |
| 업로드 실패 (개별) | "올리지 못했어요" + [재시도] |
| Viewer가 업로드 시도 | "보기 전용 멤버는 사진을 올릴 수 없어요" |

**용어 규칙 (Drive ToS 대응):** "백업", "자동 백업"이라는 단어를 UI 어디에도 쓰지 않는다. "올리기", "가족 앨범에 추가", "지정 앨범 자동 올리기"를 쓴다.

## 7. 성공 지표 (Phase 1)

| 지표 | 목표 |
|---|---|
| 온보딩 완주율 (가입 → 저장소 연결 → 첫 업로드) | 45% 이상 |
| 초대 수락률 | 60% 이상 |
| 업로드 성공률 (재시도 포함) | 99% 이상 |
| 업로드 → 타 멤버 화면 반영 지연 | p95 5초 이내 |
| Drive 재인증 발생 후 복구율 | 80% 이상 |
